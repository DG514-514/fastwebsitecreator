# Client onboarding checklist

Send this to each client once their brief arrives.

## 1. Payment
- [ ] $99 build fee paid (payment link sent with our reply)
- [ ] $10/month support plan: yes / no

## 2. Brief (the 2–3 business day clock starts when 1 and 2 are complete)
- [ ] Business name, what you do, who it's for
- [ ] Pages needed (e.g. Home, About, Services, Contact)
- [ ] Logo, photos, sketches (shared folder link)
- [ ] Text you have: services, prices, hours, contact details
- [ ] 1–3 websites you like and why
- [ ] Main action visitors should take (call, book, buy, email)

## 3. Accounts you purchase and own
- [ ] Domain name (registrar: ________)
- [ ] Business email (provider: ________)
- [ ] Hosting, if a paid plan is needed
- [ ] Payment processor (Stripe / Square / PayPal / other: ________)

## 4. Access, never by plain email or the website form
Prefer adding us as a user or delegate over sharing a password:
- [ ] Domain registrar: DNS access (e.g. GoDaddy delegate access, Namecheap "Share access", Cloudflare member)
- [ ] Payment processor: team member with developer role (Stripe "Team" → Developer)
- [ ] Email: only what's needed to set up links/forms
- If a password must be shared: use a one-time expiring link (e.g. 1Password share or onetimesecret.com)

## 5. Launch
- [ ] First draft sent
- [ ] Revisions applied (one round included)
- [ ] Domain connected, HTTPS working
- [ ] Contact, email and payment links tested end to end
- [ ] Client reminded to remove our access (unless on support)
- [ ] Ask for a testimonial and permission to feature the site
